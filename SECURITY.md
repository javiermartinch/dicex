# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest release | :white_check_mark: |
| Previous release | :x: |

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Report them privately with [GitHub's private vulnerability reporting](https://github.com/javiermartinch/dicex/security/advisories/new) ("Report a vulnerability" in the Security tab of the repository).

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact assessment
- Suggested fix (if any)

We follow [responsible disclosure](https://en.wikipedia.org/wiki/Responsible_disclosure) practices.
