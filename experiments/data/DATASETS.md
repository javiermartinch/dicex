## Sources and attribution

The datasets are obtained from OpenML (Vanschoren, van Rijn, Bischl, and Torgo 2014, *ACM SIGKDD Explorations Newsletter* 15(2):49–60), as described in Section 7.1 of the paper. Several of them originate from the UCI Machine Learning Repository (e.g., banknote authentication, Parkinson's, breast cancer Wisconsin, spambase, physicochemical protein, superconductivity); the original sources are listed on each OpenML page.

## Additional data

- `computational_study/computational_study.py` also uses the California Housing dataset, downloaded through `sklearn.datasets.fetch_california_housing`.
- `running_example/` uses synthetic data generated by the script itself (seed 42).
